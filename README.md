# FOV-Library

A lightweight, FULLY configurable FOV circle library for Roblox.

## Features

- FULLY configurable FOV circle (literally, lol)
- Performance focused & hassle-free solution
- Clean memory unloading function

## Installation

### Loadstring

The latest bundled release for effortless integration!

```lua
local FOV = loadstring(game:HttpGet("https://github.com/emulering/FOV-Library/raw/refs/heads/main/release/FOV.luau"))()
```
